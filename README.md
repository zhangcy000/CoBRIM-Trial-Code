# Model-Informed Analysis of Longitudinal Quality-of-Life Data in the coBRIM Phase III Trial

This repository contains the analysis code supporting the manuscript:

**Nonlinear Mixed Effect Modeling of Patient-Reported Outcomes to Improve Treatment Effect Estimation in an Oncology Clinical Trial**


## Overview

This repository contains R and Monolix/Simulx code used for data preparation, statistical
analysis, visualization, and model-based analyses reported in the manuscript.

The analysis evaluates longitudinal patient-reported global quality-of-life
responses using a model-informed framework.
